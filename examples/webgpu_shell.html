This page runs the Spectra C++20 plotting library compiled to WebAssembly via Emscripten. The rendering uses the WebGPU API — no Vulkan, no OpenGL, no software fallback. Requires a WebGPU-capable browser (Chrome 113+, Edge 113+, Safari 26+, or Firefox 141+ on Windows).

Try it: scroll or pinch to zoom, drag to pan, right-drag to zoom one axis, double-click to reset. Each plot zooms and pans on its own.

Supported on WebGPU (experimental 2D subset): line, scatter (including colormapped), bar, histogram, box plot, violin, band, stem, heatmap and 2D shapes, plus grid, legend, axes text and tick labels. Not yet supported: every 3D type (3D axes, line, scatter, surface, mesh, shapes). Unsupported series are skipped and listed in a notice at the bottom-left of the canvas.
